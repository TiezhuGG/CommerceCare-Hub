# Local Demo Accounts

All accounts and data are synthetic. The password is `COMMERCECARE_DEMO_PASSWORD` from the local `.env`; the default is `demo-password-change-me`.

| Role | Account | Use in demo |
| --- | --- | --- |
| Customer | `customer1@demo.local` | Own conversation, order status, delivery-delay, and after-sales request |
| Agent Operator | `operator@demo.local` | Staff ticket/trace review |
| Supervisor | `supervisor@demo.local` | Approval queue and ticket timeline |
| Admin | `admin@demo.local` | Demo reset/seed and Reliability Metrics evaluation |
