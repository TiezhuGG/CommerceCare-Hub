# Roadmap

## Near term

- Add production provider adapters behind existing contracts and retain contract tests against deterministic mocks.
- Expand natural-language handoff from supported read-only intents into explicit, policy-gated after-sales commands.
- Add richer attachment intake with malware scanning, OCR provenance, and unreadable-evidence recovery.

## Production readiness

- Integrate managed identity, secret storage, rate limiting, tracing, retention, and alerting.
- Add policy authoring workflows with review, rollout, rollback, and per-platform/shop scope.
- Add semantic evaluation judges alongside deterministic safety gates, with a human adjudication loop for disagreements.

## Experience

- Add accessible visualizations for SLA trends, approval aging, and action recovery.
- Localize customer-visible response templates and add operator assignment/queue filters.
